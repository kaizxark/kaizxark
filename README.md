## 🌌 About Me

I am a software engineer and systems architect passionate about pushing computing boundaries across **AI agent architectures**, **high-fidelity game graphics**, **bio-computational foundation models**, and **reactive enterprise web applications**. 

Whether optimizing procedural GLSL shaders on integrated silicon, orchestrating serverless NVIDIA H100 clusters for DNA variant analysis, or designing zero-latency dual-path data pipelines, I focus on building software that is **deterministic, high-signal, and extraordinarily fast**.
